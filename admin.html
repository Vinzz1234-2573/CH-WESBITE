Connect your Google Sheet

About 5 minutes, done once. After this, every form’s responses show here.

  1. Use one spreadsheet for all forms. In each Google Form: Responses tab → ⋮ → Select response destination → Select existing spreadsheet → choose the same spreadsheet. Each form gets its own tab (existing answers are copied in). Rename the tabs, for example “Volunteer”.
  2. Add the script. In that spreadsheet: Extensions → Apps Script. Delete what’s there, paste the code below (your secret is already in it), and click Save.
  3. Deploy it. Deploy → New deployment → Select type (⚙) → Web app. Set Execute as: Me and Who has access: Anyone. Click Deploy, allow the permissions Google asks for, and copy the Web app URL.
  4. Paste the URL below and click Connect.
